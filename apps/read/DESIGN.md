# The ledger's inner logic

This is a living almanac whose source happens to be a Kobo. It should feel closer to a
well-kept reference volume than a quantified-self dashboard: dense, quiet, chronological,
and rewarding when revisited.

The covers carry almost all saturated colour because the books are the subject. Teal is
reserved for accumulated evidence: progress, time, activity, and the small pulse showing
that a fresh record arrived. Paper, ink, rules, section marks, and the vertical annual date
give the rest of the page the grammar of an edited ledger.

The index exists because the mobile page is intentionally long. It behaves like a quiet
line embossed into the same paper and stays typographic so it does not turn the page into
app chrome or a detached toolbar. The freshness mark sits beside the title because the
first question in a personal data system is whether the evidence arrived.

Book portraits use progressive disclosure. The shelf stays visual and calm; the dialog
contains the forensic material: calendar, hour fingerprint, sitting shape, momentum,
metadata, and an estimate expressed as a range. The estimate refuses a single confident
date because reading cadence is lumpy.

The annual edition closes the page like a colophon and can be printed. The odd vertical
year on wide screens is the memorable hook: a spine at the end of a ledger made of books.

Motion only establishes arrival, affordance, and depth. Reduced-motion preferences erase
it. Empty days remain visible because absence is part of a reading record, not missing UI.

Highlights are intentionally absent. The statistics database can support this artifact
without copying the private contents of annotations into its public surface.
